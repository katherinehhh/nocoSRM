# SRM 核心流程与客户演示

当前本地应用已实现供应商准入、询比价、独立定标、采购确认、分批收货质检、不合格退供与补交。2026-10-12 已通过普通采购、审批、仓储及两家供应商账号的真实 HTTP 接口完成下述案例，数据保存于当前数据库。

## 从哪里开始

- [业务待办](http://127.0.0.1:13001/main/srm-workbench)：按当前角色显示可处理任务，跨角色操作后点击刷新。
- [供应商准入](http://127.0.0.1:13001/main/supply/srm/admissions)：资质、有效期、核验资料、独立审批、停用及更新资质。
- [采购询价](http://127.0.0.1:13001/main/supply/srm/rfqs)：邀请供应商、物料与数量、截止日期；查看报价对比和定标。
- [供应商报价](http://127.0.0.1:13001/main/supply/srm/quotes)：供应商选择邀请，自动带出采购明细，只填写价格、税率、交期及有效期。
- [收货质检](http://127.0.0.1:13001/main/supply/srm/inspections)：选择未过账收货单，带出明细，填写合格/不合格数及检验依据。
- [不合格退供](http://127.0.0.1:13001/main/supply/srm/returns)：选择已批准质检及已过账收货来源，登记退供、审批、发出和供应商确认。
- [财务平台](http://localhost:13002/main/finance)：独立应用、独立登录，接收合格收货与回写财务结果。

## 5分钟展示已完成案例

1. 打开[询价和报价对比](http://127.0.0.1:13001/main/supply/srm/rfqs/b57b29a7-0532-4bd0-8959-40cb0724fc45)。华东精密报价：10件×100元、税13%，含税1130元；华北制造含税1220.40元。展示采购定标理由与独立审批历史。
2. 打开[自动生成采购单](http://127.0.0.1:13001/main/supply/orders/b57b29a7-0532-4bd0-8959-40cb0724fc45)。物料、数量、价格和税率来自中选报价，采购员不能默默修改报价快照；供应商确认订单后开始交货。
3. 打开[首批质检](http://127.0.0.1:13001/main/supply/srm/inspections/d1e5d73b-e0c3-4bad-aca6-d032499ae430)与[首批收货单](http://127.0.0.1:13001/main/supply/receipts/0cb80649-db2c-4205-9cc6-e7801165fefa)。10件到货，合格6件、不合格4件；独立批准质检后只把6件计入库存，采购单仍缺4件。
4. 打开[不合格退供](http://127.0.0.1:13001/main/supply/srm/returns/f1ee22de-7958-4ee5-a263-2eeda9cb7bab)。展示仓储提交、独立审批、发出物流编号、供应商确认收回。退供不会冲减已经入库的6件合格库存。
5. 打开[补交质检](http://127.0.0.1:13001/main/supply/srm/inspections/9921eb5a-5669-4bdd-89ec-e7542c3fed54)与[补交收货单](http://127.0.0.1:13001/main/supply/receipts/5539d832-66bf-432b-9e96-bb7ac9afa1a1)。补交4件全部合格，再入库4件：物料库存合计10件、订单全部收货。
6. 切换供应商账号说明：只看到自己的邀请、报价、订单和退供，不显示竞争对手的报价或中选金额。

可这样讲：“业务台账由来源单据和实际操作驱动。审批、质检、入库、退供和补交改变业务事实后，采购剩余量、库存和待办重新计算；相关动作留有历史，重复请求不会重复入库。”

## 现场从新单开始（15—20分钟）

已准备[现场询价草稿](http://127.0.0.1:13001/main/supply/srm/rfqs/77194438-b520-4cd1-ae1d-2050bde05f79)，两家供应商与10件物料已带好；采购员可直接发布它，然后从第4步开始。

1. **采购员**新建供应商，默认为待准入；在供应商准入中选择它，填资质有效期和核验资料，提交。
2. **审批员**核验并批准，供应商启用。有效期到期或更新资质时重新审批，未批准期间不能用于新采购。
3. **采购员**新建采购询价，邀请两家有效供应商，选择“核心流程 · 精密轴承”、数量10，填写未来截止日期，发布询价。
4. **供应商A/B**各自登录，进入业务待办/供应商报价，从邀请带出明细，填单价100/108元、税率13%、承诺交期和报价有效期，提交。
5. **采购员**在询价详情对比未税、税额、含税及交期，选择有效报价并填理由；**审批员**独立批准，自动产生一张采购草稿。
6. **采购员**提交采购单，**审批员**批准，**供应商A**确认。若只演示已有准入供应商，可直接从第3步开始。
7. **仓储员**新建收货单，选择采购单与“核心流程 · 质检原料仓”，来源数量/价格带出。保存后在收货质检选择它，填写合格6、不合格4、标准与依据，提交；**审批员**批准，**仓储员**从待办进入收货单入库。
8. **仓储员**新建不合格退供，选择上述质检，填退供4件及原因；**审批员**批准；**仓储员**填写物流编号发出；**供应商A**确认收回。
9. **仓储员**选择同一采购单登记补交4件。系统带出剩余需求；创建质检4件全部合格，独立批准后入库。核对订单已收货、合格库存增加10件。

同一浏览器普通标签页共享登录，推荐独立浏览器配置文件，或逐次退出/登录。使用同一主机地址127.0.0.1，连续登录被限流时按提示等待。不要使用管理员代替独立审批。

## 与财务衔接及边界

正式过账的合格6件与补交4件分别同步财务来源（含税678元、452元）；财务端按真实供应商账单登记、核对与独立审批处理，回写结果在SRM显示。不要把“来源同步”说成“已经付款或结算”。全不合格、合格数量为0的收货不产生应付来源。财务操作说明见[财务联动](finance-bridge.zh-CN.md)，其真实账单录入要求以当前财务应用为准。

本次退供仅针对质检不合格且未作为合格库存入库的数量。已入库合格品退货、财务红字/冲销不在本次范围。报价使用人民币、整数件数；发布后的询价规格不变，审批退回可重新定标，改变规格请创建新询价。历史供应商及已过账收货按既有状态保留，新单执行准入/质检规则。

这是已验证的本地单实例流程。客户正式上线仍需真实主数据、权限与人员配置、附件管理规则、数据库备份、外部服务配置及并发/容量验收；没有连接真实银行或客户ERP。本次不修改独立财务应用代码。
